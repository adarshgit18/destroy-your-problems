# 🎯 Destroy Your Problems

> **A completely unnecessary solution to academic problems.**

**Team Name:** Adrxshverse  
**Team Lead:** Adarsh Unni  
**Institution:** Cochin University College of Engineering Kuttanad

---

## 🧠 Project Description

**Destroy Your Problems** is an interactive web experience that lets students turn academic frustrations like **attendance, assignments, and viva** into chaotic battles.

Choose your weapon, destroy the problem, and survive as the problems fight back — until the **website itself becomes the final boss.**

---

## 🤡 The Problem (that doesn't exist)

Students have a serious problem: their academic problems refuse to be destroyed.

Attendance, assignments, and viva somehow keep coming back no matter how much you try to escape them.

So we created a completely unnecessary solution:

**Destroy them.**

---

## 💥 The Solution (that nobody asked for)

Instead of solving academic problems, we destroy them.

Pick a problem, choose an unnecessarily powerful weapon, and watch it fight back — until the website itself decides that **you are the problem.**

---

## 🛠️ Technical Details

### Technologies / Components Used

#### Software

- **HTML**
- **CSS**
- **JavaScript**
- **Tailwind CSS** — UI styling and responsive layout
- **Google Material Symbols** — icons
- **Web Audio API** — sound effects and audio playback

#### Tools & Platforms

- **Google Stitch** — frontend/UI design and generation
- **Antigravity** — implementation, game logic, testing, and optimization
- **GitHub** — source control and repository hosting
- **Vercel** — deployment and hosting

### Architecture

No major frontend framework is used.

The project is built using **Vanilla JavaScript with HTML and CSS**, with all interactive game logic handled on the client side.

---

## ⚙️ Implementation

A browser-based interactive web application built using **HTML, CSS, and Vanilla JavaScript**.

The application uses client-side game logic to manage:

- Problem states
- Weapon interactions
- Animations
- Chaos progression
- Sound effects
- Final boss battle

The frontend is responsive and deployed as a static web application through **Vercel**.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/adarshgit18/destroy-your-problems.git
cd destroy-your-problems
```

Run the project locally:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
